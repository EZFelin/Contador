# 🔢 Interactive Counter

Um contador interativo desenvolvido com HTML, CSS e JavaScript para praticar conceitos básicos de frontend e manipulação do DOM.

## 🚀 Funcionalidades

* Incrementar contador
* Decrementar contador
* Resetar valor
* Alteração dinâmica de cores
* Mensagens automáticas dependendo do valor
* Botão de multiplicação x2
* Responsividade
* Efeitos hover nos botões

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 O que pratiquei nesse projeto

* Manipulação do DOM
* Eventos com `addEventListener`
* Condições com `if`
* Funções
* Alteração dinâmica de estilos
* Responsividade com CSS
* Organização de código

## 🎯 Objetivo

Esse projeto foi desenvolvido para praticar lógica de programação e conceitos básicos de JavaScript através de mini projetos.
